# Отчёт: замена вкладки «Радар» и просмотр ДЗ из расписания

## Результат

Работа выполнена в ветке `feature/week-lessons-homework`. Вкладка «Радар» удалена из навигации, а в разделе «Неделя» уроки теперь открывают модальное окно с домашними заданиями по соответствующему предмету и дню.

- Для урока без заданий показывается пустое состояние «ДЗ не задано».
- Добавлены стили для интерактивной карточки урока, бейджа количества ДЗ и содержимого модального окна.

## Связь задания с уроком

В текущей модели `Task` не содержит идентификатора урока. Поэтому для прототипа используется сопоставление:

```text
task.day === lesson.day
&& task.subject === lesson.subject (без учёта регистра и краевых пробелов)
```

Это соответствует имеющимся mock-данным, но не позволяет различить два урока одного предмета в один день. Для точной связи рекомендуется добавить в `Task` поле вроде `scheduleItemId` или `lessonNumber` и заполнять его при создании задания.

Счётчик учитывает все связанные задания, включая выполненные. Это позволяет открыть полный список заданного ДЗ, а не только незавершённые задачи.
