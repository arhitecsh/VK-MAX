# РАДАР 

> **Понимай, что важно сегодня.**

**Радар** — мини-приложение для школьников (7–11 класс), которое собирает
учебную информацию из разных мест (расписание, сообщения учителей, домашние
задания, файлы, дедлайны) и помогает понять **что сейчас действительно важно
сделать, чтобы ничего не пропустить**.

Это **первый визуальный прототип (clickable prototype)** для хакатона.
Настоящего backend, авторизации и интеграций пока нет — всё на mock-данных.

---

## 🚀 Запуск

```bash
npm install
npm run dev
```

Открой в браузере: **http://localhost:5173/**

Продакшен-сборка:

```bash
npm run build
npm run preview
```

> Основной приоритет — **мобильный экран**. На десктопе приложение
> отображается как «телефон» по центру — удобно для демонстрации жюри.

---

##  Сценарий для демонстрации

1. Открываешь приложение → видишь: *«Сегодня у тебя 2 важных дела»*.
2. Заходишь в **Входящие** → видишь сообщение от учителя физики:
   *«К четвергу подготовить лабораторную №3»*.
3. Нажимаешь **«Добавить на радар»** → задание появляется на радаре.
4. Открываешь **Радар** → видишь его среди остальных учебных событий.
5. Нажимаешь **«Я потерялся»** → приложение выделяет 2 самые важные задачи.
6. Открываешь задачу → нажимаешь **«Готово»** → карточка визуально меняется.

> Чтобы сбросить демо в исходное состояние — **Профиль → «Сбросить демо»**.

##  Экраны

| Вкладка   | Что делает                                                        |
| --------- | ----------------------------------------------------------------- |
| Главная   | Приветствие, обзор дня, «Важно сейчас», «Новое», «Я потерялся»    |
| Радар     | Визуальная карта учебной недели + ближайшие задачи                |
| Входящие  | Сообщения, которые можно превратить в задачи                      |
| Неделя    | Расписание, дедлайны и задания по дням (переключение дней)        |
| Профиль   | Статистика, настройки (заглушки), сброс демо                      |

Плюс два «наложения»: **карточка задания** и экран **«Я потерялся»**.

## 🎨 Визуальный стиль

Визуальное настроение **Сферума**: чисто, дружелюбно, технологично,
много воздуха, мягкие карточки, аккуратные скругления.

Цвет помогает ориентироваться (но не превращает интерфейс в светофор):

- 🔴 **срочно**
- 🟡 **обратить внимание**
- 🔵 **обычная информация / можно позже**
- 🟢 **выполнено**

Палитра и токены — в [`src/index.css`](src/index.css) (CSS-переменные).

- **Стек:** React 18 + TypeScript + Vite + CSS Modules.
- **Состояние:** React Context + `useState` (без внешних библиотек).
- **Подготовка к API:** данные изолированы в `data/`, типы — в `types/`,
  действия — в `context/`. Замена mock на реальный API не потребует
  переделки UI.

Подробнее — в базе знаний: [`knowledge-base/`](knowledge-base/README.md).

## ⚠️ Ограничения прототипа

Это набросок, а не production-продукт. Намеренно **не** реализовано:
авторизация, база данных, реальные API MAX, настоящая AI-модель,
уведомления, Docker, админ-панель.

ИИ в прототипе — **скрытая технология**: «понимание» сообщений и определение
приоритетов имитируется mock-данными (`suggestedTask` во входящих).
