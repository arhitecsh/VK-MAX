# 01 — Problem

## Суть проблемы

Школьная информация разбросана по разным местам:

- расписание;
- сообщения учителей;
- домашние задания;
- файлы и фотографии заданий;
- дедлайны;
- заметки;
- контрольные;
- лабораторные работы.

**Проблема не в отсутствии информации.** Проблема в том, что школьнику сложно
понять:

> **Что мне сейчас действительно важно сделать, чтобы ничего не пропустить?**

## Почему существующие решения не подходят

| Решение        | Проблема для школьника                          |
| -------------- | ----------------------------------------------- |
| Notion / Trello | Нужно вести самому, сложно, «для взрослых»      |
| Обычный календарь | Только даты, нет приоритетов и контекста      |
| Google Tasks   | Плоский список, нет связи с учебным контекстом  |
| Чат с учителем | Информация тонет в потоке сообщений             |

## Что должен дать «Мой портфель»

Ответить на вопросы:

1. Что происходит сегодня?
2. Что требует внимания прямо сейчас?
3. Какие дедлайны приближаются?
4. Что нового появилось?
5. Что я уже сделал?
6. Что можно отложить?
7. **Почему** конкретное задание вообще появилось в моём списке?
