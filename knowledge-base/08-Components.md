# 08 — Components

Карта компонентов и их ответственность.

## Компоненты (`src/components/`)

| Компонент          | Ответственность                                          |
| ------------------ | -------------------------------------------------------- |
| `BottomNavigation` | Нижняя навигация (5 вкладок), активное состояние         |
| `TaskCard`         | Карточка задачи: приоритет, предмет, дедлайн, статус     |
| `ScheduleCard`     | Карточка урока (время, предмет, кабинет, учитель)        |
| `Radar`            | Визуальная карта недели (5 дней + события + легенда)     |
| `IncomingCard`     | Карточка входящего сообщения + «Добавить на радар»       |
| `TaskDetail`       | Содержимое карточки задания (статус, источник, действия) |
| `LostScreen`       | Экран «Я потерялся» (топ-2 дела + CTA)                   |
| `PriorityBadge`    | Бейдж/точка приоритета (high/medium/low)                 |
| `StatusBadge`      | Бейдж статуса (todo/in_progress/completed)               |
| `PageHeader`       | Заголовок страницы                                       |
| `EmptyState`       | Пустое состояние секции                                  |
| `Modal`            | Bottom-sheet / диалог (backdrop, Escape, блокировка)     |

## Экраны (`src/pages/`)

| Экран     | Состав из компонентов                                   |
| --------- | ------------------------------------------------------- |
| `Home`    | hero + «Сегодня» + TaskCard×N + «Новое» + «Я потерялся» |
| `Radar`   | Radar + TaskCard×N                                       |
| `Inbox`   | IncomingCard×N                                           |
| `Week`    | day-switcher + ScheduleCard×N + TaskCard×N               |
| `Profile` | статистика + меню + сброс                                |

## Ключевые паттерны

- **Каскадная анимация** — `index` прокидывается в `TaskCard`/`IncomingCard`
  для `animationDelay`.
- **Приоритет через CSS-класс** — `styles[task.priority]` задаёт цвет акцента.
- **Модалки** — управляются флагом в контексте (`selectedTaskId`, `lostOpen`).
