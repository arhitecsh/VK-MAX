# 04 — User Flows

## Flow 1: Ежедневная проверка (основной)

```
Открыл приложение
  → Главная: «Доброе утро, Артём» + «Сегодня: 2 важных дела»
  → Видит «Важно сейчас» (2–3 карточки)
  → Открывает нужную задачу
  → Меняет статус / отмечает «Готово»
```

## Flow 2: Новое задание из входящих (демо-сценарий)

```
Входящие
  → Сообщение: «К четвергу подготовить лабораторную №3»
  → Нажимает «Добавить на радар»
  → Задача появляется на радаре
  → (опционально) Радар → видит её среди событий
```

> В прототипе это сообщение — **физика, лабораторная №3**
> (`mockMessages.ts → m-phys-lab`).

## Flow 3: «Я потерялся»

```
Главная → «Я потерялся»
  → «Спокойно, разберёмся.»
  → «У тебя 7 дел, но важны только 2»
  → 1. Контрольная по математике (сегодня, 40 мин, 🔴)
     2. Лабораторная по физике (завтра, 25 мин, 🟡)
  → «Начать с первого» → открывается задача
```

## Flow 4: Просмотр недели

```
Неделя
  → Переключает день (ПН…ПТ)
  → Видит уроки + дедлайны/задания этого дня
```

## Flow 5: Карточка задания

```
Любая задача (тап)
  → Карточка: предмет, дедлайн, источник («Откуда это?»)
  → Статус: Не начинал / В процессе / Готово
  → Файл (если есть)
  → Кнопки: Начать / Готово / Открыть материал
```
