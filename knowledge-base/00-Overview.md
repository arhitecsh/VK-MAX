# 00 — Overview

**Мой портфель** — мини-приложение для школьников, которое собирает учебную
информацию из разных мест и помогает понять, **что важно сделать сегодня**.

- **Слоган:** Понимай, что важно сегодня.
- **Статус:** первый визуальный прототип (clickable prototype) для хакатона.
- **Стек:** React 18 + TypeScript + Vite + CSS Modules.
- **Backend:** отсутствует, всё на mock-данных.

## Цель этапа

Показать, как будет выглядеть и ощущаться продукт, если школьник откроет его
каждый день. Не production — сильный визуальный набросок.

## Что уже есть в прототипе

- 4 раздела: Главная, Входящие, Неделя, Профиль.
- Карточка задания (модалка) со сменой статуса.
- Экран «Я потерялся» (умная навигация по делам).
- Рабочий сценарий: входящее сообщение → «Добавить в портфель» → задача в общем списке дел.
- Сброс демо.
