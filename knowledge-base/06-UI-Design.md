# 06 — UI Design

## Направление

Визуальное настроение **Сферума**: современный, чистый, дружелюбный,
технологичный, минималистичный. Много воздуха, мягкие карточки, аккуратные
скругления, понятная типографика.

> Мы НЕ копируем интерфейс Сферума 1-в-1 — берём цветовое настроение
> и атмосферу.

### Приоритеты (цвет = навигация)

| Уровень | Цвет      | Soft-фон   | Ощущение        |
| ------- | --------- | ---------- | --------------- |
| 🔴 high    | `#F04438` | `#FDECE9` | Срочно          |
| 🟡 medium | `#F5A623` | `#FEF3E0` | Обратить внимание |
| 🟣 low    | `#6C4AE0` | `#EFE9FF` | Можно позже     |
| 🟢 done    | `#21B573` | `#E4F7EE` | Выполнено       |

## Decision: цвет помогает ориентироваться, а не украшает

Цвет кодирует **важность и статус**, чтобы глаз мгновенно нашёл главное.
Но мы не превращаем интерфейс в «светофор»: акцент — тонкая полоска слева
на карточке + бейдж, а не залитые цветом блоки.

## Типографика

- Шрифт: системный стек (Inter → -apple-system → Segoe UI → Roboto).
- Заголовки: плотный трекинг (`letter-spacing: -0.02em`), жирные.
- Контраст: основной текст тёмный, вторичный — серый.

## Формы и тени

- Скругления: `12 / 16 / 22 / 28` px (от мелких элементов до карточек).
- Тени: мягкие, многослойные (`--shadow-sm/md/lg`).
- Карточки: белый фон, тонкая граница, лёгкая тень, подъём при hover.

## Анимации

Аккуратные, 150–400 мс, `cubic-bezier(0.22, 1, 0.36, 1)`:
- появление карточек (slide-up, каскадом);
- переходы вкладок (fade);
- модалки (bottom-sheet на мобильном, scale на десктопе);
- пульс «сегодня» на радаре;
- нажатие кнопок (scale 0.96–0.97).

## Адаптивность

- **Mobile** — приоритет (макс. ширина 440–460 px).
- **Tablet / Desktop** — приложение как «телефон» по центру экрана
  (`@media (min-width: 768px)`), модалки — по центру.
